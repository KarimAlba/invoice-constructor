# Skill: Excellent UI

## Назначение
Проектировать и собирать интерфейсы, которые выглядят как продуманный продукт, а не как шаблон из UI-kit или «типичный AI-дизайн». Цель — характер, иерархия и атмосфера, а не декоративный шум.

Не ломай существующую дизайн-систему репозитория: токены, шрифты и компоненты — пока пользователь явно не просит редизайн.

## Направление (обязательно до кода)

Выбери **одно** направление на экран/продукт и держись его:

| Направление | Характер |
|---|---|
| Editorial | Крупная типографика, поля как в журнале, асимметрия |
| Ledger / industrial | Моноширинные цифры, жёсткая сетка, «документ» |
| Brutal | Резкие границы, мало скруглений, высокий контраст |
| Refined | Тихие поверхности, один яркий акцент, воздух |
| Playful | Неожиданная геометрия, но дисциплина в палитре |

1–2 слова направления + один референс-вайб. Не смешивай «всё сразу».

## Инструкции для ИИ

1. **Иерархия и композиция первыми.** Нарисуй структуру: якорь (заголовок/цифра/документ), вторичный блок, служебное. Асимметрия, overlap, выход за сетку — если усиливают смысл. Либо щедрый воздух, либо плотная вёрстка редакции. Середина («карточки 1:1 + равные отступы») запрещена как дефолт.
2. **Типографика — голос продукта.** 2 семьи максимум: характерный display + спокойный body. Не Inter / Roboto / Arial / system-ui как единственный голос. Чёткие роли: display / headline / body / label / tabular nums. Шрифты грузить с реального источника и `font-display`.
3. **Цвет: атмосфера + один удар.** Доминирующий фон/поверхность, один острый акцент, опционально второй — редко. CSS-переменные. Не равномерная пастель и не клише purple-indigo на белом, если бренд этого не требует.
4. **Атмосфера, не плоский холст.** Градиентные сетки, grain, геометрический паттерн, слои прозрачности, жёсткая тень, декоративная рамка — только если совпадает с направлением. Текст читаем: scrim, контраст, не класть copy на шум без подложки. CSS/SVG важнее тяжёлых картинок.
5. **Motion как постановка, не конфетти.** Один вход экрана со stagger важнее десятка мелких tween. Hover/focus с явной affordance. `transform`/`opacity`, `prefers-reduced-motion`. Не анимировать всё и не крутить декоративные лупы, мешающие задаче.
6. **Состояния — часть дизайна.** Empty, loading, error, success, disabled выглядят в той же эстетике, а не как серый placeholder.
7. **Стек проекта.** Стили — CSS-модули/существующий подход репо. Не добавляй Motion/anime.js/новые шрифт-пакеты без спроса. Не жертвуй a11y ради красоты.

## Антипаттерны (generic AI look)

Не использовать без явного бренда:

- Inter + фиолетовый градиент + мягкие карточки в сетке
- Hero как маленькая картинка в рамке по центру
- Одинаковые `border-radius: 16px` и тени «как у Stripe clone»
- Иконки везде, где хватило бы типографики
- Стеклянный blur «потому что модно», не связанный с темой
- Три шрифта, пять акцентов, анимация на каждом hover

## Формат ответа

- **Направление:** [1–2 слова + вайб]
- **Решение:** [композиция, шрифты с источником, CSS-токены, что анимируется на load / hover / scroll]
- **Отвергнуто:** [какой шаблонный приём не взяли и почему]
