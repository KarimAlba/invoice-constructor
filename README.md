# Конструктор инвойса

Свой учебный фронтенд для ДЗ №2: на одном экране собирается счёт (сумма, валюта, описание, срок жизни ссылки), выдаётся платёжная ссылка, статусы `ожидает / оплачен / истёк`. Данные живут в `localStorage`, бэкенд не нужен.

Почему своё: это UI-задача про форму, пустые состояния, таймер и защиту от двойного сабмита, а не готовый вариант из приложения к занятию.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build`. Превью: `npm run preview`.

## Как пользоваться

1. Укажите сумму и валюту, при желании описание и TTL.
2. Нажмите «Выставить счёт».
3. Скопируйте ссылку или откройте её — откроется демо-экран оплаты.
4. «Отметить оплаченным» / «Оплатить (демо)» переводит счёт в `paid`. По истечении TTL статус станет `expired`.

Повторная отправка с тем же `requestKey` не создаёт второй инвойс.
