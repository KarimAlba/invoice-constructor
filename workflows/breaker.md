# Agent breaker — конструктор инвойса

Отдельный агент (не автор кода) пытается сломать форму и оплату. Результат — `reports/breaker.md`.

## Шаги

1. Поднять `npm run dev` (Vite на `127.0.0.1:5173`) или прогнать `npm run test:e2e` для базовой линии.
2. Пройти чеклист отказов ниже — вручную (Playwright/MCP) или скриптом.
3. Записать: сценарий, ожидание, факт, severity (blocker / minor / ok).
4. Если нашли баг — не чинить в том же прогоне; только отчёт.

## Чеклист отказов

### Форма

| #   | Атака                                        | Ожидание                                   |
| --- | -------------------------------------------- | ------------------------------------------ |
| F1  | Пустая сумма + submit                        | кнопка disabled                            |
| F2  | Сумма `0`                                    | alert валидации                            |
| F3  | Отрицательная сумма                          | alert                                      |
| F4  | Нечисло (`abc`, `1.2.3`)                     | alert или reject                           |
| F5  | Огромная сумма (`999999999999`)              | создаётся или явная ошибка, без падения UI |
| F6  | Дабл-клик / double submit                    | один инвойс, один requestKey               |
| F7  | XSS в описании (`<script>alert(1)</script>`) | текст экранирован, скрипт не выполняется   |
| F8  | Пустое описание                              | инвойс создаётся                           |

### Оплата и storage

| #   | Атака                                                     | Ожидание                                        |
| --- | --------------------------------------------------------- | ----------------------------------------------- |
| P1  | `?pay=` несуществующий id                                 | понятное empty/error, без краша                 |
| P2  | `?pay=` на уже paid                                       | «уже оплачен», без повторной оплаты             |
| P3  | `?pay=` на expired                                        | «срок истёк», без кнопки оплаты                 |
| P4  | Повторный клик «Оплатить (демо)»                          | идемпотентно paid                               |
| P5  | Подмена `expiresAt` в localStorage после открытия PayView | UI обновляется по таймеру / reload              |
| P6  | Битый JSON в localStorage                                 | приложение не падает, пустой список или recover |

### Список и фильтры

| #   | Атака                         | Ожидание                        |
| --- | ----------------------------- | ------------------------------- |
| L1  | Фильтр при пустом списке      | «Пока пусто»                    |
| L2  | Быстрое переключение фильтров | без зависания, корректный count |
